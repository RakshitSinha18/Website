# Rakshit Sinha — Brand Kit

A small, consistent identity for the personal / mentoring site.

## Logo
- **Monogram:** `RS` in a serif face (Georgia) on a rounded dark tile.
- **Files:** `/rs-logo.svg` (source), `/rs-logo.png` (256), `/rs-logo@512.png`.
- **Wordmark:** `/brand/wordmark.svg` + `.png` — monogram + "Rakshit Sinha" + role line.

## Colours
| Token | Hex | Use |
|---|---|---|
| Ink (bg) | `#0b0f19` | primary background |
| Ink raised | `#141a2b` | tiles, cards (top of gradient) |
| Sky | `#38bdf8` | accent start (gradient) |
| Amber | `#fbbf24` | accent end (gradient) |
| Foreground | `#f5f7fa` | primary text |
| Muted | `#8b97a8` | secondary text |

**Signature gradient:** sky `#38bdf8` → amber `#fbbf24` (the "spotlight" accent), used
diagonally on the monogram and as hairline accents.

## Type
- **Display / UI:** Geist / Helvetica Neue, semibold, tight tracking.
- **Mono / labels:** SF Mono / ui-monospace — used for taglines, skills, metadata.
- **Monogram only:** Georgia serif (deliberate contrast against the sans UI).
